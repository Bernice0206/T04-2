About This Website

This website was created as part of COS30045 to demonstrate the use of HTML, CSS and JavaScript for an interactive web-based data visualisation website.

Our Focus

We focus on appliance energy consumption information in the Australian market.

Our Data

The website uses television energy data to explore differences in screen size, technology and power consumption.

Our Goal

Our goal is to present energy information in a simple and understandable way for users.

Project Information

The television visualisations on this website were created using the cleaned dataset from T01(b). The website provides a simple way to present the findings through charts and written explanations.
